## Modern Personal Portfolio 🌌

A sleek, responsive, and professional React + Vite portfolio showcasing projects, experience, testimonials, and a contact form powered by EmailJS.

Designed with a dark, minimal aesthetic and enhanced with smooth animations, this portfolio highlights both technical expertise and creative presentation.

## Features ✨

- **Hero Section** with animated skills marquee and social links.

- **About Section** highlighting values: clean code, performance, collaboration, innovation.

- **Projects Showcase** with interactive cards, hover overlays, and CTA.

- **Experience Timeline** with glowing vertical line and alternating layout.

- **Testimonials Carousel** with navigation and dynamic indicators.

- **Contact Form** integrated with EmailJS, including success/error states.

- **Footer** with consistent branding and social links.

## Installation & Setup 🚀

Clone the repository and install dependencies:

```bash
git clone https://github.com/jdomingu19/react-tailwind-personal-portfolio.git
cd react-tailwind-personal-portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

## EmailJS Integration 📧

Install EmailJS browser package:

```bash
npm install @emailjs/browser
```

Configure environment variables in `.env`:

```bash
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```
